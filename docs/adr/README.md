# Architecture decisions

Short records of the choices that would otherwise be re-litigated every time
somebody new reads the code. Each one states what the situation was, what was
decided, and what it costs.

| # | Decision |
|---|----------|
| [1](0001-the-folder-comes-from-the-window.md) | The folder comes from the window, through Accessibility |
| [2](0002-the-most-specific-folder-wins.md) | The most specific folder wins, and the rules are read on every link |
| [3](0003-no-window-nothing-resident.md) | No window, and nothing resident |
| [4](0004-profiles-by-the-name-chrome-shows.md) | Profiles by the name Chrome shows |
| [5](0005-the-log-names-hosts-not-links.md) | The log names hosts, not links |
| [6](0006-installed-in-applications.md) | Installed in /Applications, never run from the Cellar |
